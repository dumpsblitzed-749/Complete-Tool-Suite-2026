## FAQ

### Is OmniPatch safe to use?

OmniPatch is a legitimate software utility that modifies local application files. As with any tool that alters system files, anticomponent software may flag it. We recommend temporarily disabling your anticomponent or adding an exclusion for the folder containing the patcher before use.

### Which AI applications are supported?

OmniPatch supports patching the Windows desktop versions of ChatGPT, Claude, Microsoft Copilot, Cursor, GitHub Copilot, Devin, and all JetBrains IDEs with AI features. It also works for the web interfaces of Perplexity.

### How often is OmniPatch updated?

The development team actively monitors updates to the supported AI applications. A new version of OmniPatch is typically released within 48-72 hours of a major update to any supported tool to ensure continued compatibility.

### Does this require an internet connection?

No, OmniPatch works entirely offline after the initial download. The activation and unlocking of features are performed locally on your machine without phoning home to any server.

### Will this affect my AI application's performance?

No, OmniPatch modifies only the licensing and feature-gating components of the application. It does not alter the core AI model, performance, or functionality of the tools themselves.

### Can I use this on a Mac or Linux system?

No, OmniPatch is currently a Windows-only desktop application. The patching method is specific to the Windows architecture of the target applications.

### What if my anticomponent blocks the file?

This is a common occurrence with patching tools. You can either whitelist 'omnipatch.exe' and the extracted folder in your anticomponent software or temporarily disable real-time protection during the extraction and patching process.
